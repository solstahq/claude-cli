# solsta-inc

Claude Code marketplace plugin for the [Solsta](https://www.solsta.io) build distribution platform.

## Installation

```
/plugin marketplace add https://github.com/snxd/solsta-claude
```

## Skills

| Skill | Description |
|-------|-------------|
| **solsta** | Platform overview, concepts, authentication, and skill routing |
| **solsta-cli** | Solsta CLI — products, environments, local installations, orchestration, and more |
| **solsta-api** | Solsta REST APIs — releases, repositories, update paths, teams, users, publishing, and more |

## Requirements

- [Solsta CLI](https://www.solsta.io/download) (`solsta_cli`) on your PATH
